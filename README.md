# 🏝️ 우리의 섬 (예찬 & 예형)

브라우저에서 바로 하는 둘만의 3D 섬 게임이에요. 파일 하나(`dist/index.html`)로 돌아가요.

## 하는 법
1. 둘 다 같은 주소(또는 같은 파일)를 크롬/사파리로 열기
2. 각자 캐릭터 고르기 (예찬 🐶 / 예형 🐱) → "섬에 가기"
3. 먼저 들어온 사람이 섬을 열고, 다음 사람은 자동으로 놀러 와요
4. 마이크를 허용하면 게임 안에서 바로 목소리로 대화돼요

| 조작 | PC | 모바일 |
|---|---|---|
| 이동 / 달리기 | WASD·방향키 / Shift | 왼쪽 조이스틱 (끝까지 밀면 달리기) |
| 손잡기·앉기·편지 | E 또는 Space | 분홍 버튼 |
| 감정표현 | 1~4 | 이모지 버튼 |
| 마이크 / 사진 | M / P | 🎙️ / 📷 |
| 카메라 | 드래그 회전, 휠 줌 | 화면 드래그 |

## 바꾸고 싶을 때
`src/game.js` 맨 위 `CONFIG`에서 이름, 사귄 날, 생일, 편지 내용을 바꾸고 `node build.js` 실행.

## 이벤트 미리보기 (주소 뒤에 붙이기)
- `?date=2027-08-02` → 예형 생일
- `?date=2027-04-06` → 예찬 생일
- `?date=2027-02-26` → 100일 (불꽃놀이)
- `?date=2027-11-19` → 1주년
- `?hour=18` → 노을, `?hour=22` → 밤
